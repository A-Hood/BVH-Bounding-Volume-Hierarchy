# Information
Built from https://github.com/Elliot-codling/BVH with the goal of creating a **Bounding Volume Hierarchy** as well as creating a visual representation to quickly be able to check for collision events within a scene of collision bounding boxes.

This branch is not yet adapted to BVH structure, once we have SAH set-up, then we will focus on being able to adjust the tree for efficient collision checks.

# Libraries
- SFML (2.5.1)
